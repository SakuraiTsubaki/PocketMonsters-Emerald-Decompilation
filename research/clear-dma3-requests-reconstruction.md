# Emerald `ClearDma3Requests` reconstruction

The Japanese release `bpe-j-rev0-retail` is the origin reference. All 6 cataloged releases (Japanese, English, German, French, Italian, Spanish) resolve the function from the existing `AgbMain` map and share the same 21-halfword, no-callee control-flow shape with one request-array loop and one return. The source reconstructs the manager lock, cursor reset, and clearing of the size, source, and destination fields in all 128 requests. Per-release maps preserve addresses and hashes without ROM bytes or instruction halfwords. Naming and behavior are cross-referenced to `pret/pokeemerald` commit `fe1d8e51b265851676b65885818b1f5f62586135`, `src/dma3_manager.c`.
