# Pokemon Emerald trainer-ID release catalog reconstruction

The existing Japanese reconstruction is the origin reference. Its verified function ranges were matched against every cataloged ROM without publishing the signatures. All 6 releases (Japanese, English, German, French, Italian, Spanish) contain one unique, adjacent helper sequence with identical function hashes and publication-safe Thumb control-flow evidence.

The helpers preserve the four-byte little-endian trainer-ID representation. ROM instruction bytes are not included.
