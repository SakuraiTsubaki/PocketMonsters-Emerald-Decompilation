# First repeated bootstrap callee

The Japanese BPEJ revision 0 bootstrap calls `0x080004c4` three times, making it
the first repeated target selected for deeper reconstruction. A conservative
Thumb control-flow trace covers `0x080004c4` through `0x0800054f`, observes the
return at `0x0800054e`, and records 70 reachable halfword positions.

The function has three conditional decisions (six recorded branch edges) and
five direct call sites. Its four unique direct targets are `0x0800051c`,
`0x08000540`, `0x0800aee0`, and `0x08295a08`. These remain address-based names
until behavior is established from stronger evidence.

The committed report deliberately omits raw instruction halfwords. It retains
addresses, control-flow classes, calls, edges, the complete ROM identity, and
the report hash so the trace can be reproduced locally without publishing ROM
fragments.

Reproduction:

```sh
python tools/thumb_cfg.py "Pocket Monsters - Emerald (Japan).gba" \
  --start-offset 0x4c4 \
  --max-span 0x100 \
  --expected-sha256 33f5610b9186b4add09fef68895deb00f552b997b3d133b5a961e5123506343c \
  --omit-raw-halfwords \
  --output analysis/emerald-jp-callee-080004c4.json
```
