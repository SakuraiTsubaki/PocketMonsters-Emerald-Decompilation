# Tools

Target-specific tools for Pocket Monsters Emerald live here.

Each tool receives its own directory with implementation, README, tests, fixtures, configuration, manifests, logs, generated non-ROM examples, and verification results. Commit every storable non-ROM output needed to inspect or reproduce behavior.

Document supported builds, inputs, outputs, dependencies, determinism, errors, safety constraints, and verification commands. Tools producing graphics, sprites, palettes, fonts, icons, or tiles must retain actual PNG output.

Put target-independent implementations in [`SakuraiTsubaki/Decompilation`](https://github.com/SakuraiTsubaki/Decompilation).
